## ⑥ Win10 与 Win11 各跑一遍文件关联，五个扩展名各准备一个样本文件逐个双击验证

**状态**: 待办

验收标准：
- 在 Windows 10 上运行 `mdvn.exe --register`，验证以下五个扩展名的文件关联：
  - `.md` - Markdown 标准扩展
  - `.markdown` - 完整拼写
  - `.mdown` - 缩写形式 1
  - `.mkd` - 缩写形式 2
  - `.mdtext` - 文本标记
- 双击各扩展名的样本文件，验证能通过 mdvn 打开
- 运行 `mdvn.exe --unregister`，验证关联被正确移除
- 在 Windows 11 上重复上述测试
- 使用 Process Monitor 确认卸载后注册表无残留

**备注**：需要两个不同的 Windows 版本、Process Monitor 工具，当前 AI 执行环境不具备。

## ⑧ F5 手动重载

**状态**: 待办

验收标准：

### ⑧-a 外部编辑器改文件后按 F5 的内容更新与位置恢复

- 用 mdvn 打开一个 Markdown 文件
- 在外部编辑器（如记事本）修改该文件
- 按 F5，验证：
  - 内容已更新，显示新的修改
  - 阅读位置按块下标尽量保持（"大致回到刚才那一段"）

### ⑧-b 文件被删后按 F5 的降级提示

- 用 mdvn 打开一个 Markdown 文件
- 在外部删除或移动该文件
- 按 F5，验证：
  - 窗口内容不消失（不变成白屏）
  - 给出错误提示，告知文件已删除
  - 可再次按 F5 重试

### ⑧-c 连按 100 次的内存曲线

- 用 mdvn 打开一个 Markdown 文件
- 连续按 F5 至少 100 次
- 记录内存使用量（`PrivateUsage`）：
  - 前 5 次的均值
  - 后 5 次的均值
  - 验证后 5 次的均值不高于前 5 次（无单调上升，即无内存泄漏）

**备注**：需要真实 Windows 环境和内存监测工具，当前 AI 执行环境不具备。
