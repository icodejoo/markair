# markair

Windows 专用、只读的极轻量 Markdown 查看器。双击 `.md` 秒开，常驻内存 15MB 级 —— 比目前实测最好的第三方方案（mdviewer，约 95MB）再低 6 倍以上。

## 安装

下载发布 zip → 解压到任意目录 → 双击 `markair.exe` 即用。**无需安装、无需管理员权限、不写注册表**（除非显式执行 `--register`，见下）。

**首次运行的 SmartScreen 提示**：markair 未购买代码签名证书（成本与体量不匹配），首次运行 Windows SmartScreen 会拦截并提示"Windows 已保护你的电脑"。这是未签名 exe 的正常表现，不是病毒告警：点击"更多信息" → "仍要运行"即可继续。

## 文件关联

`markair.exe --register` 与 `markair.exe --unregister` 一次性处理以下 **5 个扩展名**：`.md`、`.markdown`、`.mdown`、`.mkd`、`.mdtext`。

- 退出码：**0 成功，1 失败**（包括 `--register` 与 `--unregister` 同时给出这种歧义场景）。
- 两个开关都必须在没有其他 markair 窗口打开时执行（一次性动作，不弹窗，结果通过控制台输出）。
- **"注册"只是把 markair 加进该扩展名的"打开方式"候选列表，不等于让 markair 成为默认程序**。现代 Windows（8 及以上）的默认程序关联受 `UserChoice` 注册表键的哈希保护，第三方程序无法（也不应该）绕过它去抢占默认程序——任何声称能自动设为默认程序的工具都是在撒谎或使用非法手段。若要把 markair 设为某扩展名的默认程序，请手动执行：设置 → 应用 → 默认应用 → 按文件类型指定默认应用 → 找到对应扩展名 → 选择 markair。

## 卸载

先执行一次 `markair.exe --unregister`（清理文件关联的注册表项），再直接删除 markair 所在目录即可，注册表零残留。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 滚动一行 / 翻页 / 到开头结尾 | 方向键 / `Page Up` `Page Down` / `Home` `End`、鼠标滚轮 |
| 查找 | `Ctrl+F` 打开查找条，`Enter`/`F3` 下一个，`Shift+Enter`/`Shift+F3` 上一个，`Esc` 关闭查找条 |
| 缩放字号 | `Ctrl++` 放大、`Ctrl+-` 缩小、`Ctrl+0` 复位；`Ctrl+滚轮` 效果相同 |
| 切换主题 | `Ctrl+Shift+T`（系统跟随 / 浅色 / 深色三态循环） |
| 大纲侧栏 | `Ctrl+\` 开关（默认关闭） |
| 历史前进 / 后退 | `Alt+←` 后退，`Alt+→` 前进 |
| 打开文件 | `Ctrl+O` |
| 打开文件夹（侧栏浏览） | `Ctrl+Shift+O` |
| 选中正文并复制 | 鼠标拖选（支持跨段落/标题/代码块/表格），`Ctrl+C` 复制纯文本（无右键菜单） |
| 重新加载当前文档 | `F5`（不带任何修饰键） |
| 关闭窗口 | `Ctrl+W` 或 `Esc`（查找条打开时 `Esc` 先关查找条） |

## 界面与功能

- **底部操作栏**：常驻显示，左侧 8 个图标按钮——文件列表（文件夹侧栏）、大纲、打开文件、打开文件夹、主题切换、字体缩小、字体放大、查找；最右侧固定贴右的是复制当前文件路径（仅在有文档打开时出现）与历史记录。
- **文件夹侧栏**：浏览/过滤当前目录下的 Markdown 文件，支持按文件名过滤、逐项"打开所在文件夹"/"新窗口打开"。挤压式常驻面板（会占用正文可用宽度），只能通过底部栏"文件列表"按钮开关，`Esc` 对它不生效。
- **历史记录侧栏**：`Alt+←`/`Alt+→` 前进后退之外，也可通过底部栏"历史"按钮展开一份可视化的历史列表，逐条"打开所在文件夹"/"新窗口打开"/删除。悬浮抽屉，`Esc` 可关闭。
- **大纲侧栏**：`Ctrl+\` 或底部栏"大纲"按钮开关，默认关闭；关闭时不占用任何内存/CPU（组件本身在关闭状态下不存在实例）。悬浮抽屉叠加在正文之上，不挤占正文宽度；随滚动位置自动高亮当前阅读到的标题。
- **查找条**：`Ctrl+F` 打开，输入后按 `Enter`/`F3` 触发全文搜索并跳到下一处命中，`Shift+Enter`/`Shift+F3` 跳到上一处，`Esc` 关闭；采用"回车才搜"策略，输入过程中不会逐字符重新扫描全文。
- **打开文件对话框**：`Ctrl+O`（或底部栏"打开文件"按钮、欢迎屏按钮）弹出标准 Windows 文件选择框，选中后在**当前进程内新开一个窗口**打开。
- **文档内链接点击**：外部链接（`http`/`https`/`mailto`/`file`）交给系统默认程序打开，不内嵌浏览；`.md` 链接在当前进程内新开一个窗口打开（不是原地替换，也不再另起进程）；`#锚点` 按 GitHub 式规则滚动到本文档内对应标题。除以上白名单 scheme 外的链接（如 `javascript:`）一律拒绝执行。
- **窗口状态记忆**：退出前记住窗口位置与大小，下次启动的新窗口默认出现在同一位置；同一位置已有窗口时按固定偏移层叠展开，避免完全重叠。
- **欢迎屏**：没有文档打开时显示"打开文件"/"打开文件夹"两个引导按钮，取代早期版本的示例 Markdown。
- **多开行为**：同一进程内可以打开多个窗口（点击文档内 `.md` 链接、"打开文件"、文件夹/历史侧栏的"新窗口打开"均在本进程内新建窗口，不再各自派生独立进程）；仅当所有窗口都关闭后整个进程才退出。双击资源管理器里的 `.md` 文件仍会各自拉起一个新的 markair.exe 进程——常驻内存的"15MB 级"是单进程基准，同进程内追加窗口共享该基准的绝大部分开销，不是每个窗口线性叠加 15MB。

## 已知限制

- **暂不支持 Windows 高对比度模式**：当前 markair 针对标准浅色/深色主题优化，在系统高对比度模式下的显示效果和易用性无法保证。
- markair 并非对外部主动网络请求为零：① 默认自动加载网络图片（`load_remote_images=1`），文档打开后网络图片会在首屏之后自动发起下载，可在 `state.ini` 手动设 `load_remote_images=0` 关闭（关闭后显示占位块，点击占位块仍可单次加载该图）；② 每次非 bench 模式启动都会在后台静默检查 GitHub Releases 是否有新版本，发现后自动下载校验并在下次启动时自我替换，**目前没有提供关闭该检查的开关**。这两者是当前唯一会主动联网的行为，其余（打开/渲染本地文档）不发起任何网络请求。
- 只读，不可编辑。
- SVG 图片走 [lunasvg](https://github.com/sammycage/lunasvg) 离线栅格化（vendored，见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)），支持 shape / gradient / clip-path / mask；**不支持 filter**（`feGaussianBlur` 等特效，图标级场景通常用不到）。
